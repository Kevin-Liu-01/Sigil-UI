## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `nodes` (required) | `FlowNode[]` | — | Nodes configuration. |
| `connections` (required) | `FlowConnection[]` | — | Connections configuration. |
| `direction` | `"horizontal" \| "vertical"` | — | Direction configuration. |
| `connector` | `"solid" \| "dashed" \| "dashed-animated"` | — | Connector configuration. |
