
## Usage

```tsx
<TreeDiagram
    root={{
      id: "root",
      label: "App",
      variant: "accent",
      children: [
        { id: "api", label: "API", children: [
          { id: "auth", label: "Auth" },
          { id: "db", label: "Database" },
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `root` (required) | `TreeDiagramNode` | — | Root configuration. |
| `connector` | `"solid" \| "dashed"` | — | Connector configuration. |
| `compact` | `boolean` | — | Compact configuration. |
