## Usage

```tsx

    yLabels={["High Impact", "Low Impact"]}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `cells` (required) | `MatrixCell[][]` | — | Cells configuration. |
| `xLabels` | `string[]` | — | X Labels configuration. |
| `yLabels` | `string[]` | — | Y Labels configuration. |
| `xAxisLabel` | `string` | — | X Axis Label configuration. |
| `yAxisLabel` | `string` | — | Y Axis Label configuration. |
