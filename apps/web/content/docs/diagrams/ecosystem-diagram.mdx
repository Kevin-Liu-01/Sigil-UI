## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `center` (required) | `{ label: string; icon?: ReactNode; sublabel?: string }` | — | Center configuration. |
| `ring` (required) | `EcosystemNode[]` | — | Ring configuration. |
| `size` | `number` | — | Sets the component's size. |
