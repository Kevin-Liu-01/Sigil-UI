```tsx

    <DiagramLabel text="Input" variant="default" showDot />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `text` (required) | `string` | — | Text configuration. |
| `variant` | `"default" \| "accent" \| "warn"` | — | Selects a supported visual treatment. |
| `showDot` | `boolean` | — | Show Dot configuration. |
| `showLine` | `boolean` | — | Show Line configuration. |
| `lineLength` | `number` | — | Line Length configuration. |
| `position` | `"top" \| "bottom" \| "left" \| "right"` | — | Position configuration. |
