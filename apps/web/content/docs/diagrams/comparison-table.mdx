## Import

```tsx
import { ComparisonTable } from "@sigil-ui/components";
```

## Usage

```tsx
<ComparisonTable
    columns={["Sigil", "Typical UI kit"]}
    features={[
      { name: "Token coverage", values: { Sigil: true, "Typical UI kit": false } },
      { name: "Live presets", values: { Sigil: true, "Typical UI kit": false } },
      { name: "Agent constraints", values: { Sigil: true, "Typical UI kit": false } },
    ]}
  />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `features` | `ComparisonFeature[]` | — | Feature rows to compare. |
| `columns` | `string[]` | — | Column names (keys matching the values in features). |
