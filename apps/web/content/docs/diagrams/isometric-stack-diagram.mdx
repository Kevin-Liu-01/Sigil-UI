## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `layers` (required) | `IsoStackLayer[]` | — | Layers configuration. |
| `width` | `number` | — | Width of the rendered content. |
| `layerHeight` | `number` | — | Layer Height configuration. |
| `gap` | `number` | — | Gap configuration. |
