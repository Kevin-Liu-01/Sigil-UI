## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `series` | `AreaChartSeries[]` | — | — |
| `width` | `number` | — | — |

| `showGrid` | `boolean` | `true` | Show grid lines. |
| `curve` | `"smooth" \| "linear"` | `smooth` | Curve type. |
