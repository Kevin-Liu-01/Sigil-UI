## Usage

```tsx
<StatusTable
    title="System Status"
    services={[
      { name: "API", status: "operational", uptime: "99.98%", lastIncident: "14 days ago" },
      { name: "Database", status: "operational", uptime: "99.99%" },
      { name: "CDN", status: "degraded", uptime: "99.90%", lastIncident: "2 hours ago" },
```

| Prop | Type | Default | Description |

| `title` | `string` | — | Heading displayed in the component. |
