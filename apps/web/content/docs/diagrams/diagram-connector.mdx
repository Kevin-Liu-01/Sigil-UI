## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `ConnectorVariant` | — | Selects a supported visual treatment. |
| `direction` | `ConnectorDirection` | — | Direction configuration. |
| `label` | `string` | — | Readable label for the component. |
| `length` | `number` | — | Length configuration. |
| `strokeColor` | `string` | — | Stroke Color configuration. |
| `arrowSize` | `number` | — | Arrow Size configuration. |
