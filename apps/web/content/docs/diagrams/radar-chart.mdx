
```tsx
<RadarChart
    axes={[
      { label: "Speed" },
      { label: "Power" },
      { label: "Range" },

      { label: "Accuracy" },
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `axes` (required) | `RadarAxis[]` | — | Axes configuration. |
| `series` (required) | `RadarSeries[]` | — | Series configuration. |
| `width` | `number` | — | Width of the rendered content. |
| `height` | `number` | — | Height of the rendered content. |
| `rings` | `number` | — | Rings configuration. |
