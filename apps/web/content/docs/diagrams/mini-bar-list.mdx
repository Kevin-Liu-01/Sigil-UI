## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` | `MiniBarItem[]` | — | — |
| `valueLabel` | `string` | `Count` | Value label (shown in header). |
| `formatValue` | `(v: number) => string` | — | Format value for display. |
| `color` | `string` | — | Color for all bars if not set per-item. |
