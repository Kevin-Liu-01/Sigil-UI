
## Usage

```tsx
<FunnelChart
    steps={[
      { label: "Visitors", value: 10000 },
      { label: "Signups", value: 3200 },
      { label: "Active", value: 1800 },
      { label: "Paid", value: 450 },
    ]}
  />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `steps` | `FunnelStep[]` | — | — |
| `showRates` | `boolean` | `true` | Show conversion rate between steps. |
| `showValues` | `boolean` | `true` | Show absolute values. |
