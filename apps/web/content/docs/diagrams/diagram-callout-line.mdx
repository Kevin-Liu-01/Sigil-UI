## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `path` (required) | `string` | — | Path configuration. |
| `label` | `string` | — | Readable label for the component. |
| `labelX` | `number` | — | Label X configuration. |
| `labelY` | `number` | — | Label Y configuration. |
| `dotX` | `number` | — | Dot X configuration. |
| `dotY` | `number` | — | Dot Y configuration. |
| `active` | `boolean` | — | Active configuration. |

## Token integration
