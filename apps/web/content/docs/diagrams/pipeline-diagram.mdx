## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `steps` (required) | `PipelineStep[]` | — | Steps configuration. |
| `direction` | `"horizontal" \| "vertical"` | — | Direction configuration. |
| `connector` | `"solid" \| "dashed" \| "dashed-animated"` | — | Connector configuration. |
| `showNumbers` | `boolean` | — | Show Numbers configuration. |
