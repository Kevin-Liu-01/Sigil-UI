## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `layers` | `IsolationLayer[]` | — | Stacked isolation layers (outer to inner). |
| `columns` | `ComparisonColumn[]` | — | Comparison matrix columns. |
| `rows` | `ComparisonRow[]` | — | Comparison matrix rows. |
