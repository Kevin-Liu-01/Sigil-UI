## Import

```tsx
import { DiagramNode } from "@sigil-ui/components";
```

## Usage

```tsx
<DiagramNode label="API gateway" sublabel="Routes incoming requests" badge="Healthy" />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `icon` | `ReactNode` | — | Icon configuration. |
| `label` (required) | `string` | — | Readable label for the component. |
| `sublabel` | `string` | — | Sublabel configuration. |
| `variant` | `DiagramNodeVariant` | — | Selects a supported visual treatment. |
| `size` | `DiagramNodeSize` | — | Sets the component's size. |
| `mono` | `boolean` | — | Mono configuration. |
| `badge` | `ReactNode` | — | Badge configuration. |
