```tsx
<SpecTable
    title="GPU Specifications"
    groups={[
      {
        title: "Performance",
        rows: [
          { label: "TFLOPS", value: "312", unit: "FP16", highlight: true },
          { label: "Memory", value: "80", unit: "GB HBM3" },
          { label: "Bandwidth", value: "3.35", unit: "TB/s" },

        title: "Physical",
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `rows` | `SpecRow[]` | — | Ungrouped rows (use when no grouping needed). |
| `groups` | `SpecGroup[]` | — | Grouped rows with section headings. |
| `title` | `string` | — | Title shown at top. |
