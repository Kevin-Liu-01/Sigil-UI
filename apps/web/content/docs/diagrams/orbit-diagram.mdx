    center={{ label: "Sigil" }}

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `center` (required) | `{ label: string; icon?: ReactNode }` | — | Center configuration. |
| `nodes` (required) | `OrbitNode[]` | — | Nodes configuration. |
| `size` | `number` | — | Sets the component's size. |
| `labels` | `string[]` | — | Labels configuration. |
