
## Usage

```tsx
<SigilNavbar variant="inline" fixed={false} className="w-full">
    <a href="/" className="font-semibold text-[var(--s-text)] no-underline">Sigil UI</a>
    <div className="ml-auto flex items-center gap-[var(--s-space-4)]">
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `"full" \| "inline"` | `full` | "full" — renders its own 5-column grid so the nav content aligns with the SigilPageGrid content column, with structural gutter borders flanking the nav. "inline" — a plain `<nav>` with a bottom border, suitable for nesting inside a SigilPageGrid content column. / |
| `contentMax` | `number` | — | — |
| `railGap` | `number` | — | — |
| `gridCell` | `number` | — | — |
| `fixed` | `boolean` | — | — |
| `gutterPattern` | `GutterPattern` | — | — |
| `marginPattern` | `GutterPattern` | — | — |
| `showGutterGrid` | `boolean` | — | — |
| `showMarginLines` | `boolean` | — | — |
