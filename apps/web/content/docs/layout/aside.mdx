## Usage

```tsx
<Aside sticky={false} width="100%" className="p-[var(--s-space-16)]"><h3>Project details</h3><p>Updated today</p><p>Three contributors</p></Aside>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `width` | `number \| string` | — | Width of the rendered content. |
| `sticky` | `boolean` | — | Sticky configuration. |
| `borderSide` | `"left" \| "right" \| "none"` | — | Border Side configuration. |
