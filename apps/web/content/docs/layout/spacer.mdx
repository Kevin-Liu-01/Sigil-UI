## Preview

<ComponentPreview>
  <Flex className="w-full"><Badge>Start</Badge><Spacer /><Badge>End</Badge></Flex>
</ComponentPreview>

## Import

```tsx
import { Flex, Badge, Spacer } from "@sigil-ui/components";
```

## Usage

```tsx
<Flex className="w-full"><Badge>Start</Badge><Spacer /><Badge>End</Badge></Flex>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `height` | `number \| string` | — | Fixed height (block spacer). If omitted, grows to fill flex space. |
| `width` | `number \| string` | — | Fixed width (inline spacer). |
