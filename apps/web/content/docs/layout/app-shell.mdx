## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `header` | `ReactNode` | — | Header configuration. |
| `sidebar` | `ReactNode` | — | Sidebar configuration. |
| `footer` | `ReactNode` | — | Footer configuration. |
| `sidebarWidth` | `number \| string` | — | Sidebar Width configuration. |
| `sidebarPosition` | `"left" \| "right"` | — | Sidebar Position configuration. |
