## Import

```tsx
import { Margin } from "@sigil-ui/components";
```

## Usage

```tsx
<Margin visible className="w-full"><div className="p-[var(--s-space-16)] bg-[var(--s-surface)]">Content between the margin rails</div></Margin>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `"sm" \| "md" \| "lg"` | `md` | Rail size. |
| `visible` | `boolean` | — | Show visible border rail indicators. |

## Token integration

| CSS Variable | Purpose |
|---|---|
| `--s-border-muted` | Border muted |
