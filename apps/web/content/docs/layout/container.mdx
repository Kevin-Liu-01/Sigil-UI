## Preview

<ComponentPreview>
  <Container><p>Content follows the preset’s maximum reading width.</p></Container>

## Import

```tsx
import { Container } from "@sigil-ui/components";
```

## Usage

```tsx
<Container><p>Content follows the preset’s maximum reading width.</p></Container>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `"narrow" \| "default" \| "wide"` | `default` | Width variant. |
| `center` | `boolean` | `true` | Center the container. |

## Token integration

| CSS Variable | Purpose |
|---|---|
| `--s-content-max-narrow` | Content max narrow |
| `--s-content-max` | Content max |
| `--s-content-max-wide` | Content max wide |
| `--s-page-margin` | Page margin |
