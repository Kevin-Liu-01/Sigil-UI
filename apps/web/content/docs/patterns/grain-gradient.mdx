## Import

```tsx
import { GrainGradient } from "@sigil-ui/components";
```

## Usage

```tsx
<div style={{position:"relative",width:"100%",height:120,borderRadius:8,overflow:"hidden"}}>
    <GrainGradient />
  </div>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `tint` | `GrainTint` | `accent` | Tint color of the grain overlay. |
| `intensity` | `GrainIntensity` | `medium` | Noise intensity. |
