## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `PatternVariant` | `dots` | Pattern type. |
| `opacity` | `number` | `0.1` | Pattern opacity. |
| `scale` | `number` | `1` | Scale of the pattern. |
