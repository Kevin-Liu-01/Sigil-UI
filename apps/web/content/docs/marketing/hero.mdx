## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` | `ReactNode` | — | Headline text. |
| `description` | `ReactNode` | — | Supporting description text. |
| `actions` | `HeroAction[]` | — | CTA action buttons. |
