## Usage


## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `sliders` (required) | `CostSlider[]` | — | Sliders configuration. |
| `estimate` (required) | `CostEstimate` | — | Estimate configuration. |
| `sliderRenderer` | `(slider: CostSlider) => ReactNode` | — | Slider Renderer configuration. |
