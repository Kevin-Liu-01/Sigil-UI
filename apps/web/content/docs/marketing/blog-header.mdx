## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` (required) | `string` | — | Heading displayed in the component. |
| `accent` | `string` | — | Accent configuration. |
| `subtitle` | `string` | — | Subtitle configuration. |
| `categories` | `string[]` | — | Categories configuration. |
| `activeCategory` | `string` | — | Active Category configuration. |
| `onCategoryChange` | `(category: string) => void` | — | On Category Change configuration. |
| `icon` | `ReactNode` | — | Icon configuration. |
