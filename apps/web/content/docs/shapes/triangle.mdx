## Import

```tsx
import { Triangle } from "@sigil-ui/components";
```

## Usage

```tsx
<Triangle size="xl" />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `direction` | `"up" \| "down" \| "left" \| "right"` | `up` | Direction the triangle points. |
| `size` | `"sm" \| "md" \| "lg" \| "xl"` | `md` | Triangle size. |
