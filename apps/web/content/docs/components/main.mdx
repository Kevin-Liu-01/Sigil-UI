title: Main

---

## Preview

<ComponentPreview>
  <Main className="border border-dashed border-[var(--s-border)] p-6">Main content area</Main>
</ComponentPreview>

## Import

```tsx
import { Main } from "@sigil-ui/components";
```

## Usage

```tsx
<Main className="border border-dashed border-[var(--s-border)] p-6">Main content area</Main>
```

## Custom max-width

```tsx
<Main maxWidth="800px">
  Narrower content area
</Main>
```

## Disable centering

```tsx
<Main center={false}>
  Left-aligned main content
</Main>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `maxWidth` | `string` | `"var(--s-content-max, 1200px)"` | Maximum width of the content area |
| `center` | `boolean` | `true` | Center the element with auto margins |
| `className` | `string` | — | Additional CSS classes |
