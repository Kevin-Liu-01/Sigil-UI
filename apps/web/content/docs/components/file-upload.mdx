## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `accept` | `string` | — | Accept configuration. |
| `multiple` | `boolean` | — | Multiple configuration. |
| `maxSize` | `number` | — | Max Size configuration. |
| `disabled` | `boolean` | — | Prevents user interaction when enabled. |
| `onChange` | `(files: File[]) => void` | — | Called when the value changes. |
