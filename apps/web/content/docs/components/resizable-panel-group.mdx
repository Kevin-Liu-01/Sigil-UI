## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Direction of the panel layout. |
| `children` | `ReactNode` | — | Panels separated by resize handles. |
