## Usage

```tsx
<NumberField defaultValue={42} />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `number` | — | The current controlled value. |
| `defaultValue` | `number` | — | Initial value when the component manages its own state. |
| `onValueChange` | `(value: number) => void` | — | Called when the user changes the value. |
| `min` | `number` | — | Smallest allowed value. |
| `max` | `number` | — | Largest allowed value. |
| `step` | `number` | — | Amount added or removed by each adjustment. |
| `disabled` | `boolean` | — | Prevents user interaction when enabled. |
