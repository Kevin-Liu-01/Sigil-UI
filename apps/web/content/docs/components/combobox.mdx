## Import

```tsx
import { Combobox } from "@sigil-ui/components";
```

## Usage

```tsx
<Combobox placeholder="Select framework..." options={[{ value: "next", label: "Next.js" }, { value: "remix", label: "Remix" }, { value: "astro", label: "Astro" }]} />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `options` (required) | `ComboboxOption[]` | — | Options configuration. |
| `value` | `string` | — | The current controlled value. |
| `defaultValue` | `string` | — | Initial value when the component manages its own state. |
| `onValueChange` | `(value: string) => void` | — | Called when the user changes the value. |
| `placeholder` | `string` | — | Hint shown before a value is entered. |
| `searchPlaceholder` | `string` | — | Search Placeholder configuration. |
| `emptyText` | `string` | — | Empty Text configuration. |
| `className` | `string` | — | Additional classes merged with the component styles. |
