## Import

```tsx
import { Editable } from "@sigil-ui/components";
```

## Usage

```tsx
<Editable defaultValue="Click to edit" />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `string` | — | The current controlled value. |
| `defaultValue` | `string` | — | Initial value when the component manages its own state. |
| `onChange` | `(value: string) => void` | — | Called when the value changes. |
| `placeholder` | `string` | — | Hint shown before a value is entered. |
| `disabled` | `boolean` | — | Prevents user interaction when enabled. |
