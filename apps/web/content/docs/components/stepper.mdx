## Usage

```tsx
<Stepper currentStep={1} steps={[{ label: "Account", description: "Your details" }, { label: "Workspace", description: "Team settings" }, { label: "Review", description: "Confirm and finish" }]} />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `steps` (required) | `StepperStepConfig[]` | — | Steps configuration. |
| `currentStep` (required) | `number` | — | Current Step configuration. |
| `orientation` | `"horizontal" \| "vertical"` | — | Orientation configuration. |
