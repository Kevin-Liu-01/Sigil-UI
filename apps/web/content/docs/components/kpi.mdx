```tsx

```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | — | Metric label. |
| `value` | `string \| number` | — | Current value. |
| `change` | `string` | — | Change amount (e.g. "+12.5%"). |
| `trend` | `"up" \| "down" \| "neutral"` | `neutral` | Trend direction. |
