## Import

```tsx

```

## Usage

```tsx
<TreeView
    defaultExpanded={["src"]}
    data={[{ id: "src", label: "src", children: [{ id: "components", label: "components" }, { id: "utils", label: "utils" }] }]}
  />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `data` (required) | `TreeNode[]` | — | Data used to render the visualization. |
| `defaultExpanded` | `string[]` | — | Default Expanded configuration. |
| `onSelect` | `(id: string) => void` | — | On Select configuration. |
| `selectedId` | `string` | — | Selected Id configuration. |
