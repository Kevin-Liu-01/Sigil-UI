## Import

```tsx
import { Box3DGrid } from "@sigil-ui/components";
```

## Usage

```tsx
<Box3DGrid
  columns={3}
  items={[
    { key: "tokens", children: "Tokens", hoverLift: true },
    { key: "components", children: "Components", hoverLift: true },
    { key: "presets", children: "Presets", hoverLift: true },
  ]}
/>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` | `Box3DGridItem[]` | — | Items to display in the grid. |
| `columns` | `number` | `3` | Number of columns. |
| `gap` | `string \| number` | `1.5rem` | Gap between boxes. |
