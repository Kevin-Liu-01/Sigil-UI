## Import

```tsx
import { IsometricScene } from "@sigil-ui/components";
```

## Usage

```tsx
<IsometricScene width="100%" height={260} showGrid><IsometricPrism width={120} height={80} depth={60} /></IsometricScene>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `showGrid` | `boolean` | — | Show Grid configuration. |
| `gridSize` | `number` | — | Grid Size configuration. |
| `width` | `number \| string` | — | Width of the rendered content. |
| `height` | `number \| string` | — | Height of the rendered content. |
| `children` | `ReactNode` | — | Content rendered inside the component. |
