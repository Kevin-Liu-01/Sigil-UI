## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` (required) | `ReactNode` | — | Heading displayed in the component. |
| `description` | `ReactNode` | — | Supporting text below the heading. |
| `actions` | `CTAAction[]` | — | Actions configuration. |
| `variant` | `"centered" \| "split"` | — | Selects a supported visual treatment. |
| `media` | `ReactNode` | — | Media configuration. |
