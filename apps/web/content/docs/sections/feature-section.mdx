## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | — | Readable label for the component. |
| `title` (required) | `ReactNode` | — | Heading displayed in the component. |
| `description` | `ReactNode` | — | Supporting text below the heading. |
| `features` (required) | `FeatureItem[]` | — | Features configuration. |
| `columns` | `2 \| 3 \| 4` | — | Columns configuration. |
| `align` | `"left" \| "center"` | — | Align configuration. |
