
## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | — | Section label. |
| `heading` | `string` | — | Section heading. |
| `cards` | `BlueprintCardData[]` | — | Cards to render in a 2-column staggered grid. |
