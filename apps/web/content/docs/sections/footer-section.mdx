## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `logo` | `ReactNode` | — | Logo configuration. |
| `tagline` | `string` | — | Tagline configuration. |
| `groups` (required) | `FooterLinkGroup[]` | — | Groups configuration. |
| `socials` | `{ label: string; href: string; icon: ReactNode }[]` | — | Socials configuration. |
| `copyright` | `string` | — | Copyright configuration. |
| `legal` | `{ label: string; href: string }[]` | — | Legal configuration. |
