
## Usage

```tsx
<Stack gap="var(--s-space-8)"><TabularValue size="xl">$12,840.00</TabularValue><TabularValue muted>+1,280.50 this month</TabularValue></Stack>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `TabularValueSize` | `sm` | Size preset. |
| `as` | `"span" \| "div" \| "td" \| "p" \| "dd" \| "time"` | `span` | Render as a different element. |
| `muted` | `boolean` | `false` | Muted text color. |

## Token integration

| CSS Variable | Purpose |
|---|---|
