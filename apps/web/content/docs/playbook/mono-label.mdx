## Import

```tsx
import { MonoLabel } from "@sigil-ui/components";
```

## Usage

```tsx
<MonoLabel>MonoLabel example</MonoLabel>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `MonoLabelVariant` | `muted` | Visual variant. |
| `size` | `MonoLabelSize` | `xs` | Size preset. |
| `as` | `"span" \| "p" \| "label" \| "div" \| "dt" \| "dd"` | `span` | Render as a different element (e.g. "p", "label", "div"). |

## Token integration

| CSS Variable | Purpose |
|---|---|
| `--s-text-muted` | Text muted |
| `--s-primary` | Primary |
| `--s-text` | Text |
| `--s-font-mono` | Font mono |
